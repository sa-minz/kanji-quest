# 🈶 Kanji Quest

**Kanji Quest** is an interactive Japanese Kanji learning game built with **React and Vite**. It is designed to make learning Japanese Kanji more engaging through a simple, game-based learning experience.

🔗 **Live Demo:** https://kanji-quest-pi.vercel.app/
💻 **GitHub:** https://github.com/sa-minz/kanji-quest

---

## 🎮 About the Project

Kanji Quest combines Japanese language learning with a game-style interface to help learners practice and recognize Kanji characters.

The project was developed as a **frontend web application using React**, with Vite used as the development and build tool.

The main goal is to provide a simple and interactive way for beginners to practice Japanese Kanji while improving their recognition and understanding.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/sa-minz/kanji-quest.git
```

### 2. Navigate to the Project

```bash
cd kanji-quest
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will be available through the local development URL provided by Vite.

---

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
